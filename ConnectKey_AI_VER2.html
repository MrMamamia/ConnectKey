Mobile, Termux & APK Deployment
Android, Termux & Offline
1 Install as Android App (WebAPK / PWA)
Via Browser Menu

Android automatically compiles and installs a native WebAPK when added from your mobile browser:

Steps for Chrome, Brave, Edge & Samsung Internet:
1. Tap the three vertical dots (⋮) in the top-right corner of your browser.
2. Tap "Install app" (or "Add to Home screen").
3. Tap Install when prompted.
Android will create a native app icon on your home screen and app drawer that opens fullscreen.
2 Run Locally in Termux (Android Terminal)

Because ConnectKey.AI is 100% self-contained in a single file, you can run it right inside Termux using Python's built-in web server: 

# 1. Update Termux & install python
pkg update -y && pkg install python curl -y

# 2. Download ConnectKey single-file
curl -sSL "https://connectkeyai.vercel.app/" -o index.html

# 3. Host locally and launch in browser
python -m http.server 8080 &
termux-open-url http://localhost:8080
3 Package as a Standalone .apk File

Want an actual .apk installer package to sideload or share? You can generate one in 60 seconds with Microsoft's official PWABuilder tool without needing Android Studio:

  1. Copy your live app URL using the "Copy App URL" button below.
  2. Click "Open PWABuilder" to visit PWABuilder.com (it opens with your URL preloaded).
  3. Click Start > select Android > click Package APK.
  4. Download the generated .apk and install it directly on your Android phone!
